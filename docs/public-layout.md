# Layout público

O contexto público usa um route group do App Router em `apps/web/app/(public)`. Assim, Header e Footer são compartilhados pelas páginas do marketplace sem aparecer em áreas internas, como `/design-system`.

## Elementos disponíveis

- Header fixo com identidade Riddy.
- Navegação desktop para aluguel, funcionamento e proprietários.
- Ações de entrada e cadastro preparadas para a futura etapa de autenticação.
- Menu móvel em Sheet acessível, com fechamento após a navegação.
- Link de salto para o conteúdo principal.
- Container responsivo com largura máxima de 1440px.
- Footer institucional responsivo.

Os links de seções e autenticação são estruturais nesta etapa. Seus fluxos e conteúdos serão implementados nas etapas correspondentes.
