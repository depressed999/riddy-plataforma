# Design System da Riddy

A biblioteca inicial de componentes fica em `apps/web/components/ui` e segue os tokens do `DESIGN.md` fornecido como referência visual.

## Princípios aplicados

- Ciano `#00FFFF` reservado a ações primárias e estados selecionados.
- Texto escuro sobre ciano para manter contraste.
- Superfícies brancas sobre fundo off-white.
- Bordas `#E2E8F0` no lugar de sombras em conteúdo comum.
- Geist para títulos e labels; Inter para conteúdo.
- Raios pequenos, espaçamento em múltiplos de 4px e transições curtas.
- HTML semântico, foco visível e componentes Radix para overlays.

## Componentes disponíveis

- `Button`
- `Input`
- `Select`
- `Badge`
- `Card`
- `Dialog`
- `Sheet`
- `DropdownMenu`
- `Skeleton`

## Demonstração

Com o frontend ativo, acesse `http://localhost:3000/design-system` para visualizar variantes, estados e padrões de uso.

Dark mode não foi criado porque o `DESIGN.md` define somente o tema claro nesta fase.
